# Full-stack Developer Capstone Project

**Repository name:** Cars-Dealership

**Project name:** Cars Dealership – Full-stack Web Application

## Description
A responsive web application for Cars Dealership, a national car retailer in the U.S.
Users can browse dealership branches, filter dealers by state, read reviews,
and post their own reviews with sentiment analysis after logging in.

## Tech stack
React, Django, Flask, Node.js, Express, MongoDB, SQLite,
Docker, Kubernetes, IBM Cloud Code Engine, GitHub Actions
